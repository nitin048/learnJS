Module 01

JavaScript Architecture & Engine Foundations

▶ 00:00 Intro & Setup

1. What is JavaScript?

JavaScript is a high-level, single-threaded, garbage-collected, interpreted (or JIT-compiled), dynamic language with a non-blocking event loop. It conforms to the ECMAScript (ES) specification.

💡
Sheryians Key Insight
JavaScript does not directly understand human English code. The browser uses a JavaScript Engine (like Google Chrome's V8, Firefox's SpiderMonkey, or Safari's JavaScriptCore) to convert source code into machine-executable binary bytecode.

2. How the V8 Engine Runs Code

⚙️ V8 Pipeline Under the Hood
1. Parser & AST
Code is tokenized into lexical units and transformed into an Abstract Syntax Tree (AST).
2. Ignition Interpreter
Converts the AST into unoptimized bytecode for instantaneous startup execution.
3. TurboFan JIT Compiler
Monitors "hot functions" (frequently called code) and compiles them into highly optimized machine code.

3. Execution Context & The Call Stack

Everything in JavaScript happens inside an Execution Context. When JS code runs, the Global Execution Context (GEC) is created with two distinct phases:

  1. Memory Creation Phase (Variable Environment): Memory is allocated for variables and functions. `var` is initialized to `undefined`, functions are copied completely.
  2. Code Execution Phase (Thread of Execution): Code is executed line by line synchronously from top to bottom.
⚡ JavaScript Execution Flow 
// Execution Context & Call Stack Demo
function first() {
  console.log("Entering first()");
  second();
  console.log("Exiting first()");
}

function second() {
  console.log("Inside second()");
}

console.log("Global Execution Started");
first();
console.log("Global Execution Finished");

Variables, Declarations & Hoisting

▶ 10:20 Variables & Hoisting

1. `var` vs `let` vs `const`

In modern JavaScript (ES6+), variable declarations differ drastically by scope, hoisting behavior, and re-assignment capabilities.

Feature var (ES5) let (ES6) const (ES6)
Scope Function / Global Block Scoped { } Block Scoped { }
Hoisting Hoisted & initialized as undefined Hoisted into TDZ (Temporal Dead Zone) Hoisted into TDZ (Temporal Dead Zone)
Re-declaration ✅ Allowed in same scope ❌ SyntaxError ❌ SyntaxError
Re-assignment ✅ Allowed ✅ Allowed ❌ TypeError (Constant)
Initial Value Required? No No ✅ Yes (Must initialize at declaration)

2. Hoisting & The Temporal Dead Zone (TDZ)

Hoisting is JavaScript's default behavior of moving declarations to the top of the current scope during the Memory Creation phase.

⚠️
The TDZ Trap
let and const ARE hoisted, but they cannot be accessed until their declaration line is executed. The region between entering the scope and the declaration is called the Temporal Dead Zone (TDZ). Accessing them inside TDZ throws a ReferenceError: Cannot access 'x' before initialization.
⚡ Hoisting & Scope Code Demo 
// 1. var Hoisting Demo
console.log("hoistedVar:", hoistedVar); // logs 'undefined'
var hoistedVar = "Declared with var";

// 2. Block Scope Isolation
{
  var globalPollution = "I leak outside!";
  let blockSafe = "I stay inside!";
  const constSafe = 42;
}
console.log(globalPollution); // Accessible!
// console.log(blockSafe);   // ReferenceError: blockSafe is not defined

// 3. Temporal Dead Zone Demonstration
try {
  console.log(tdzVar); // ReferenceError
  let tdzVar = "Hello TDZ";
} catch (err) {
  console.error("TDZ Caught:", err.message);
}
Module 03

Data Types & The JavaScript Type System

▶ 01:06:48 (5815s Topic Zone)

1. Primitive vs Reference Types

JavaScript divides all values into two categories based on how they are stored and managed in memory:

🧠 Memory Allocation Architecture
Primitive Types (Stack)
• Number, String, Boolean, Undefined, Null, Symbol, BigInt
• Stored directly in the Stack Memory
• Immutable & passed by value (copies actual value).
Reference Types (Heap)
• Object, Array, Function, Date, Map, Set
• Stored in the dynamic Memory Heap
• The Stack only stores a Pointer / Reference Address to the Heap!
💡
Sheryians Golden Rule of References
When you assign an object/array to another variable (e.g. let b = a), you are NOT making a copy of the data. Both variables point to the exact same memory address in the Heap. Modifying one mutates the other!

2. Type Coercion: Implicit vs Explicit

Type coercion is the automatic or manual conversion of values from one data type to another.

  • String Coercion: Whenever + is used with any string operand, JS converts all operands to strings and concatenates (e.g. "5" + 2 === "52").
  • Numeric Coercion: Operators like -, *, /, % convert operands into numbers (e.g. "5" - 2 === 3).
  • Boolean Coercion: Values converted inside if() or with Boolean() / !!.

3. The 8 Falsy Values in JavaScript

⚠️
Must Memorize Falsy List
There are only 8 falsy values in JavaScript: false, 0, -0, 0n (BigInt zero), "" (empty string), null, undefined, and NaN.
EVERYTHING ELSE IS TRUTHY (including [], {}, "0", "false", and negative numbers like -1).
⚡ Type Quirks & Deep Cloning 
// 1. Primitive Copy vs Reference Mutation
let primitiveA = 50;
let primitiveB = primitiveA;
primitiveB = 100;
console.log("primitiveA:", primitiveA); // 50 (Unchanged!)

let refArr1 = ["Sheryians", "Coder"];
let refArr2 = refArr1; // Shared pointer!
refArr2.push("JavaScript Pro");
console.log("refArr1 length:", refArr1.length); // 3 (Mutated!)

// 2. Safe Deep Cloning with modern structuredClone()
let original = { name: "Harsh", details: { city: "Bhopal" } };
let deepCloned = structuredClone(original);
deepCloned.details.city = "Bangalore";
console.log("original city:", original.details.city); // "Bhopal" (Safe!)

// 3. Type Coercion Edge Cases
console.log("[] == false:", [] == false); // true!
console.log("[] == ![]:", [] == ![]);     // true! (Coerced to 0 == 0)
console.log("typeof null:", typeof null); // "object" (Historical bug)
console.log("typeof NaN:", typeof NaN);   // "number"
Module 04

Operators & Expressions

▶ 02:03:57 Operators

1. Comparison: Strict (`===`) vs Loose (`==`)

Always default to strict equality (===) in production code:

  • == (Abstract Equality): Coerces operand types if they differ before comparison (e.g. 5 == "5" is true).
  • === (Strict Equality): Compares both value AND data type without any coercion (e.g. 5 === "5" is false).

2. Logical Short-Circuiting (`&&`, `||`, `??`)

Logical operators in JavaScript don't just return booleans; they return the actual operand value:

  • A && B (AND): Returns A if A is falsy; otherwise returns B.
  • A || B (OR): Returns A if A is truthy; otherwise returns B.
  • A ?? B (Nullish Coalescing): Returns B ONLY if A is null or undefined. If A is 0, "", or false, it returns A.
⚡ Short-Circuit & Nullish Coalescing 
// Difference between || and ??
let userScore = 0; // 0 is a valid score!

let display1 = userScore || 100;
console.log("Using || fallback:", display1); // 100 (Bug! Overrode 0)

let display2 = userScore ?? 100;
console.log("Using ?? fallback:", display2); // 0 (Correct! 0 preserved)

// Short-circuiting execution
let isLoggedIn = true;
isLoggedIn && console.log("User is authenticated, welcome back!");

// Ternary Operator
let age = 19;
let status = age >= 18 ? "Eligible to vote" : "Underage";
console.log("Status:", status);
Module 05

Control Flow & Branching

▶ 02:51:12 Control Flow

1. Conditionals (`if`, `else if`, `else`)

Execute different blocks of code based on truthy/falsy evaluation.

2. The Clean Code Pattern: Guard Clauses / Early Return

Instead of deeply nesting multiple if-else ladders, modern JavaScript developers use Guard Clauses to exit early.

⚡ Guard Clauses vs Nested Ifs 
// ❌ Bad: Deeply Nested
function processPaymentBad(user, amount) {
  if (user) {
    if (user.isActive) {
      if (user.balance >= amount) {
        user.balance -= amount;
        return "Success";
      } else {
        return "Insufficient Balance";
      }
    } else {
      return "User Inactive";
    }
  } else {
    return "No User";
  }
}

// ✅ Good: Guard Clauses (Clean, Flat, Scalable)
function processPaymentClean(user, amount) {
  if (!user) return "No User";
  if (!user.isActive) return "User Inactive";
  if (user.balance < amount) return "Insufficient Balance";

  user.balance -= amount;
  return `Success! New Balance: ${user.balance}`;
}

const client = { isActive: true, balance: 500 };
console.log(processPaymentClean(client, 150));
Module 06

Loops & Iterations

▶ 03:20:40 Loops

1. The Core Loop Types

  • for loop: Known number of iterations with counter initialization, condition, and increment/decrement.
  • while loop: Entry-controlled loop; checks condition before running the body.
  • do...while loop: Exit-controlled loop; guaranteed to execute at least ONCE even if condition is false.
  • for...of: Iterates directly over values of iterables (Arrays, Strings, Sets, Maps).
  • for...in: Iterates over enumerable property keys of an Object (or indices of an Array).
⚡ Loops & Break/Continue 
// 1. for...of vs for...in
const fruits = ["Apple", "Banana", "Cherry"];

console.log("=== for...of (Values) ===");
for (const fruit of fruits) {
  console.log("Fruit:", fruit);
}

console.log("\n=== for...in (Indices / Keys) ===");
for (const index in fruits) {
  console.log(`Index ${index} => ${fruits[index]}`);
}

// 2. Control Statements: break and continue
console.log("\n=== break & continue Demo ===");
for (let i = 1; i <= 6; i++) {
  if (i === 3) {
    console.log(`Skipping iteration ${i} with continue`);
    continue;
  }
  if (i === 5) {
    console.log(`Breaking loop at ${i}`);
    break;
  }
  console.log("Step:", i);
}

Functions Deep Dive & First-Class Citizens

▶ 04:39:18 Functions

1. Function Declarations vs Expressions vs Arrow Functions

In JavaScript, functions are First-Class Citizens: they can be assigned to variables, passed as arguments to other functions, and returned from functions.

Feature Function Declaration Function Expression Arrow Function (ES6)
Syntax function greet() {} const greet = function() {} const greet = () => {}
Hoisting Full function hoisted Variable hoisted (TDZ for let/const) Variable hoisted (TDZ for let/const)
this binding Dynamic (caller context) Dynamic (caller context) Lexical (inherits from parent scope)
arguments object ✅ Available ✅ Available ❌ Not available (Use ...rest)

2. Higher-Order Functions (HOFs) & Callbacks

A Higher-Order Function is any function that takes another function as an argument or returns a function. The passed function is called a Callback.

⚡ HOFs, Callbacks & Closures Demo 
// 1. Higher-Order Function Demonstration
function calculate(num1, num2, operationCallback) {
  return operationCallback(num1, num2);
}

const add = (a, b) => a + b;
const multiply = (a, b) => a * b;

console.log("Addition via HOF:", calculate(10, 5, add));       // 15
console.log("Multiply via HOF:", calculate(10, 5, multiply)); // 50

// 2. Rest Parameters (...args)
function sumAll(...numbers) {
  return numbers.reduce((sum, n) => sum + n, 0);
}
console.log("Sum of multiple args:", sumAll(1, 2, 3, 4, 5)); // 15

// 3. Closure Preview (Function Returning Function)
function multiplier(factor) {
  return function(number) {
    return number * factor; // 'factor' is remembered in closure!
  };
}
const double = multiplier(2);
const triple = multiplier(3);
console.log("Double 8:", double(8)); // 16
console.log("Triple 8:", triple(8)); // 24
Module 08

Arrays & Modern Array Methods

▶ 06:17:14 Arrays

1. Mutating vs Non-Mutating Methods

Modern JS emphasizes immutability. Knowing whether an array method mutates the original array or returns a new one is critical:

  • Mutating (In-place): push(), pop(), shift(), unshift(), splice(), sort(), reverse().
  • Non-Mutating (Pure/Immutable): map(), filter(), reduce(), slice(), concat(), find(), some(), every(), toSorted().

2. The Big Three: `map`, `filter`, `reduce`

🔄 Functional Array Pipeline
map(fn)
Transforms every item 1-to-1 into a new array of the exact same length.
filter(fn)
Selects elements matching a boolean predicate into a new filtered array.
reduce(fn, init)
Boils down an entire array into a single accumulated result (number, object, array).
⚡ Array Pipeline & Reduce Masterclass 
// E-commerce Cart Calculation
const cart = [
  { item: "MacBook Pro", price: 2000, category: "Tech", qty: 1 },
  { item: "Coffee Mug", price: 15, category: "Lifestyle", qty: 2 },
  { item: "Wireless Mouse", price: 50, category: "Tech", qty: 2 },
  { item: "Notebook", price: 10, category: "Stationery", qty: 3 }
];

// 1. Filter Tech items
const techItems = cart.filter(p => p.category === "Tech");
console.log("=== Tech Items ===");
console.table(techItems);

// 2. Calculate Total Cart Value with reduce
const grandTotal = cart.reduce((total, item) => {
  return total + (item.price * item.qty);
}, 0);
console.log("Grand Total Price: $" + grandTotal);

// 3. Group by Category using reduce
const grouped = cart.reduce((acc, item) => {
  acc[item.category] = acc[item.category] || [];
  acc[item.category].push(item.item);
  return acc;
}, {});
console.log("Grouped by Category:", grouped);
Module 09

Objects & References Deep Dive

▶ 07:16:36 Objects

1. Dot Notation vs Bracket Notation

Use Dot notation (obj.prop) for standard static keys. Use Bracket notation (obj[prop]) when:

  • The property key is stored inside a variable: const key = "email"; obj[key]
  • The key contains special characters or spaces: obj["first-name"]
  • The key is dynamic or computed at runtime.

2. Modern Object Utility Methods

  • Object.keys(obj): Returns array of property names.
  • Object.values(obj): Returns array of property values.
  • Object.entries(obj): Returns array of [key, value] pairs.
  • Object.freeze(obj): Makes object 100% immutable (no adding, removing, or editing properties).
  • Object.seal(obj): Prevents adding or removing properties, but allows modifying existing writable properties.
⚡ Object Destructuring & Freeze 
// 1. Dynamic Keys & Object Destructuring
const role = "admin";
const user = {
  id: 101,
  username: "akshat_dev",
  profile: {
    roleName: role,
    location: "India"
  }
};

// Nested destructuring with aliasing & defaults
const { username, profile: { roleName: userRole, location }, status = "active" } = user;
console.log(`User: ${username} | Role: ${userRole} | Status: ${status}`);

// 2. Object Immutability: Object.freeze vs Object.seal
const immutableConfig = Object.freeze({ apiEndpoint: "https://api.domain.com", timeout: 5000 });
// immutableConfig.timeout = 10000; // Silently ignored in non-strict mode, throws TypeError in strict mode!
console.log("Config timeout remains:", immutableConfig.timeout);

// 3. Object.entries loop
const stats = { views: 15400, likes: 980, shares: 320 };
console.log("=== Analytics Entries ===");
for (const [metric, count] of Object.entries(stats)) {
  console.log(`${metric.toUpperCase()}: ${count}`);
}

💡 Top Tricky JavaScript Interview Questions

Curated tricky questions frequently asked in frontend interviews at top tech companies.

• [] + {} evaluates to "[object Object]". The + operator coerces [] to an empty string "" via [].toString(), and {}.toString() produces "[object Object]". Result: "" + "[object Object]" = "[object Object]".

• {} + [] in a standalone browser console line may evaluate to 0 because the leading {} is parsed as an empty code block, and +[] is treated as unary plus on an empty array, coercing it to 0! (Inside an expression like ({} + []) it evaluates to "[object Object]").

In the IEEE 754 floating-point standard used by JavaScript, NaN (Not-a-Number) is a special numeric value representing an undefined or unrepresentable mathematical result (e.g. 0 / 0 or parseInt("hello")).

Because NaN !== NaN (it is never equal to itself), you should NEVER check with val === NaN. Always use Number.isNaN(val) (which checks if the value is strictly NaN without type coercion) rather than the global isNaN().

JavaScript represents all numbers using 64-bit binary floating-point format (IEEE 754). Numbers like 0.1 and 0.2 have repeating infinite binary fractions and cannot be represented with exact precision in binary. 0.1 + 0.2 yields 0.30000000000000004.

Solution: Use Number.EPSILON or rounding: Math.abs((0.1 + 0.2) - 0.3) < Number.EPSILON (returns true).

• Function Declarations: function foo() {} are hoisted entirely during the memory creation phase. You can safely call foo() anywhere in the scope, even before its definition line.

• Function Expressions: const foo = function() {} assign an anonymous function to a variable. The variable declaration is hoisted, but the function assignment occurs only at execution time. Calling foo() before that line throws a ReferenceError (if let/const) or TypeError: foo is not a function (if var).

• map(): Returns a brand new array containing the results of calling the provided function on every element. It does not mutate the original array and is chainable with .filter() or .reduce().

• forEach(): Executes a provided function once for each array element and always returns undefined. It is strictly used for side-effects (e.g. logging or mutating external state) and is not chainable.

A Closure is the combination of a function bundled together (enclosed) with references to its surrounding state (the lexical environment). In simple terms: a function remembers the variables from the outer scope where it was created, even after that outer function has finished executing.

Real-World Use Cases:

  • Creating private variables & data encapsulation (Module pattern).
  • Debouncing and Throttling functions for search inputs / scroll handlers.
  • Currying and Function Factories.
  • Maintaining state in asynchronous timer callbacks and event listeners.

1. Array Unique Values

Write a function getUnique(arr) that takes an array with duplicates and returns an array with only unique values using both ES6 Set and filter().

// Challenge 1: Return Unique Elements
function getUnique(arr) {
  // Method 1: Using Set
  const setUnique = [...new Set(arr)];
  
  // Method 2: Using filter & indexOf
  const filterUnique = arr.filter((item, idx) => arr.indexOf(item) === idx);

  return { setUnique, filterUnique };
}

const numbers = [1, 2, 2, 3, 4, 4, 5, 1, 6];
console.log("Original:", numbers);
console.log("Unique Result:", getUnique(numbers));

2. Flatten a Nested Array

Write a recursive function flattenArray(arr) without using the built-in Array.prototype.flat().

// Challenge 2: Deep Flatten Array using Recursion & Reduce
function flattenArray(arr) {
  return arr.reduce((acc, curr) => {
    if (Array.isArray(curr)) {
      return acc.concat(flattenArray(curr));
    } else {
      return acc.concat(curr);
    }
  }, []);
}

const nested = [1, [2, [3, [4, 5]], 6], 7];
console.log("Flattened:", flattenArray(nested)); // [1, 2, 3, 4, 5, 6, 7]

3. Word Frequency Counter

Given a sentence string, return an object representing the frequency of each word using reduce().

// Challenge 3: Word Frequency Counter
function countWordFrequency(str) {
  const words = str.toLowerCase().replace(/[^a-zA-Z0-9\s]/g, '').split(/\s+/);
  
  return words.reduce((acc, word) => {
    if (!word) return acc;
    acc[word] = (acc[word] || 0) + 1;
    return acc;
  }, {});
}

const text = "JavaScript is great, and JavaScript is versatile!";
console.log("Frequency Result:", countWordFrequency(text));
